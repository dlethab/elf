Data export

{% include "admin/_nav.html" %}

A ZIP of the archive's public data, as JSON and as CSV files that open in a spreadsheet. Use it for preservation copies, for researchers, or to move the archive to new software.

  • It contains only published, public records, and only the fields their public pages show.
  • Confidential fields are never included: research and editor notes, donor and custodian details, interview codes, redaction notes, accounts, submissions, contact messages and logs.
  • Oral-history transcripts and translations are included only where the interviewee's consent allows publication and no embargo is in force.
  • Media files are not included. Every record carries the address of its page.
  • Each download is recorded in the audit log.

This is not a backup. For a complete copy of everything, including confidential data and media files, follow the backup procedure in docs/OPERATIONS.md.
