Import from a spreadsheet

{% include "editor/_nav.html" %}

Upload a CSV file of one kind of record. You will see a preview with every problem before anything is created. Imported rows become submissions in the review queue; nothing is published until reviewed.

  1. Download the template for the kind of record, fill it in a spreadsheet program, and save as CSV UTF-8 (this keeps Tigrinya and Arabic text intact).
  2. Use the same formats as the contribution forms. Dates: 1952, 1952-03, c. 1952, 1950s, 1950 to 1955. References to other records: their permanent ID (for example plc-abc12345) or their exact name.
  3. Several aliases in one cell: separate with ;. Several sources: separate with ||, each as Title | page | URL.
  4. Only enter facts you can source. Leave unknown values empty.
